## Как смотреть проекты

Каждый проект лежит в отдельной папке и содержит:
- `README.md` внутри папки — с описанием задачи, хода решения и выводов
- Jupyter Notebook или `.py` файл с кодом
- Дашборды — ссылки или скриншоты
